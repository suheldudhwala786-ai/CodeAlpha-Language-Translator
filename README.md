# 🌍 CodeAlpha Language Translator

> **A modern, responsive, and user-friendly Language Translation Web Application built with HTML, CSS, and JavaScript, powered by a Translation API.**

This project was developed as **Task 1** for the **CodeAlpha Frontend Development Internship**. It provides a clean and intuitive interface for translating text between multiple languages in real time while demonstrating API integration, asynchronous JavaScript, and responsive UI design.

---

## ✨ Features

* 🌍 Translate text between multiple languages
* ⚡ Real-time translation using Translation API
* 🎯 Clean and minimal user interface
* 📱 Fully responsive design for desktop and mobile
* 🔄 Asynchronous API requests using Fetch API
* 🎨 Modern card-based layout with soft shadows
* 📝 Multi-line text input
* 🚀 Fast and lightweight application
* 💡 Beginner-friendly and easy to extend

## 🚀 How to Run

1. Clone the repository

```bash
git clone https://github.com/yourusername/CodeAlpha-Language-Translator.git
```

2. Open the project folder

3. Launch `index.html` in any modern web browser

4. Enter your text

5. Select the target language

6. Click **Translate**
